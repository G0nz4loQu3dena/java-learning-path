## Objetivo del módulo

<div align="justify">

Aprender la sintaxis básica de Java: cómo se ve un programa mínimo, cómo se declaran variables y tipos, cómo se opera con ellas, cómo se controla el flujo de ejecución (decisiones y repeticiones), y cómo se organiza código en métodos reutilizables. Es la base sobre la que se apoya todo lo demás — sin esto, nada del resto del repositorio tiene sentido.

</div>

## Orden recomendado

<div align="justify">

Seguir el orden numérico — cada proyecto da por hecho lo que se vio en el anterior (por ejemplo, `control-flujo` ya asume que sabes declarar variables y usar operadores).
