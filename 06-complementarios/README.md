## Objetivo del módulo

<div align="justify">

Módulo abierto, sin un temario fijo desde el principio — se va definiendo con temas de la librería estándar de Java que no encajaban en los módulos anteriores, pero que se usan constantemente en aplicaciones reales. Arranca con el manejo moderno de fechas y horas.

</div>
