## Objetivo del módulo

<div align="justify">

Salir de "lo mínimo para que compile" y empezar a usar piezas de la librería estándar de Java que vas a necesitar constantemente: manejo de texto de forma eficiente, arrays de tamaño fijo, y — algo crítico en cualquier programa real — qué hacer cuando algo sale mal, sin que la aplicación se caiga de forma abrupta y sin control.

</div>
